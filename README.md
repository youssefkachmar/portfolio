## 💼 Featured Infrastructure Project

### **Secure Azure Cloud Infrastructure**
> [GitHub Repository URL](https://github.com/youssefkachmar/azure-secure-infrastructure)

A complete, production-ready zero-trust enterprise network simulated on Microsoft Azure IaaS leveraging secure hub-and-spoke virtual networks and multi-layered defenses.

- **Central Security Gateways:** Managed pfSense virtual firewall appliance with custom routing rule layers, NAT configurations, and secure OpenVPN administration tunnels.
- **Strict Network Segmentation & UDRs:** Outbound flows strictly funneled through security NVAs utilizing Azure User-Defined Routes (UDRs) to block flat network movement.
- **Enterprise Core Systems:** Windows Server instances running Active Directory Services (AD DS, DNS, GPOs) orchestrating centralized user identity, paired with HAProxy edge reverse-proxies for SSL offloading.
- **SOC Monitoring Pipeline:** Fully integrated Intrusion Detection/Prevention (Suricata), host/system compliance logging (Wazuh SIEM), and live server telemetry (Zabbix).
