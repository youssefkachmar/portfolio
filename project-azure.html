Infrastructure

A comprehensive, zero-trust cloud network deployment on Microsoft Azure featuring strict Hub-and-Spoke segmentation, IDS/IPS threat detection, and centralized SIEM monitoring.

Role Network Architect
Environment Microsoft Azure IaaS
Security Model Zero-Trust / Hub-and-Spoke

Traffic & Routing Control

To eliminate the risks of a flat network, the architecture was segmented into dedicated subnets: AD/DNS, Web, Client, VoIP, and Management.

Using Azure User Defined Routes (UDRs), all inter-subnet and outbound traffic is forcefully funneled through the central pfSense Network Virtual Appliance (NVA). This strictly prohibits internal machines from bypassing the firewall.

Central Gateway

The pfSense Firewall acts as the absolute core of the security perimeter, handling strict LAN/WAN filtering, Network Address Translation (NAT), and providing a secure OpenVPN tunnel for remote administration using PKI certificates.

Identity & Proxy

Windows Server runs Active Directory (AD DS) to centralize IAM. Externally, an internal Nginx server is published using HAProxy on the gateway, handling SSL-offloading and hiding internal IPs.

IDS/IPS & SIEM Monitoring

To defend the perimeter dynamically, Suricata (IDS/IPS) actively analyzes network flows to detect and block malicious signatures, successfully mitigating simulated Nmap port scans.

Total operational visibility is maintained using Zabbix for real-time hardware monitoring, while Wazuh (SIEM/HIDS) aggregates system logs to detect anomalies and provide a comprehensive Security Operations Center (SOC).
